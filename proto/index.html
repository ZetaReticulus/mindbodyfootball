How these were built

  • Procedural three.js in the ThreeUI style — geometry generated in code, so there are no .glb model files and nothing to download.
  • three.js r149 (MIT) is vendored locally at proto/vendor/, so the prototypes work offline and can't break from a CDN outage.
  • Every scene uses only your logo colours: teal #00B48E, aqua #87E9E7, green #8EC66C, slate #5B8196.
  • All three honour prefers-reduced-motion and pause rendering when the tab is hidden, so they don't drain a phone battery.
  • Credit: technique adapted from Meng To's open-source ThreeUI (MIT).
